# List of changes:
* Dirt to __Sand__ using the dripstone method of Mud to Clay.
* __Coal Ore__ using Coal and Stone/Deepslate/Cobbled Deepslate.
* __Diamond Ore__ using Diamond and Stone/Deepslate/Cobbled Deepslate.
* __Emerald Ore__ using Emerald and Stone/Deepslate/Cobbled Deepslate.
* __Iron Ore__ using Iron and Stone/Deepslate/Cobbled Deepslate.
* __Gold Ore__ using Gold and Stone/Deepslate/Cobbled Deepslate.
* __Copper Ore__ using Copper Blocks, Copper and Stone/Deepslate/Cobbled Deepslate.
* __Lapis Lazuli Ore__ using Lapis Block and Stone/Deepslate/Cobbled Deepslate.
* __Redstone Ore__ using Redstone and Stone/Deepslate/Cobbled Deepslate.
* Smelt __Iron Block__ from a Raw Iron Block.
* Smelt __Gold Block__ from a Raw Gold Block.
* Smelt __Copper Block__ from a Raw Copper Block.
